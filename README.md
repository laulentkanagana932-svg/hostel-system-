# Hostel Management System

## Description
Hostel Management System is a simple web-based application developed using HTML, CSS, and JavaScript. The system helps manage hostel operations such as student registration, room management, and room allocation.

## Features
- User Login
- User Registration
- Student Management
  - Add Students
  - View Students
  - Delete Students
- Room Management
  - Add Rooms
  - View Rooms
- Room Allocation
- Data Storage using LocalStorage

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage
